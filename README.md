# My Configuration

This is just a collection of files that I install on my Macs that makes
my development life easier. A lot of it just makes the command line easier
to use with git.

# Files

 - .bash_profile - simple bash profile
 - .git-completion.bash - command line completion for git
 - .git-prompt.sh - add nice stuff to your bash prompt if in a repo
 - .gitconfig - my git config w/ several aliases
 - bin/ruby.sh - launch a shell that has SQL*Builder key mappings, log on to ruby, useful for time entry, etc. Doesn't do you a lot of good if you don't work where I work... :)
 - .vimrc and .vim - all of my vim config


A note on the vim config, after installing .vim be sure to do the following
- `:PlugInstall`
- `:CocInstall coc-snippets`
